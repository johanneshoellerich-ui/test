# SAA Private Banking Tool

Ein Strategic Asset Allocation Tool für Private Banking, entwickelt mit React und TypeScript.

## Features

- **Risikoprofile**: Konservativ, Ausgewogen, Wachstumsorientiert, Aggressiv
- **Asset-Klassen**: Aktien, Anleihen, Immobilien, Rohstoffe, Cash, Alternative Investments
- **Portfolio-Optimierung**: Automatische Allokation basierend auf Risikoprofil
- **Visualisierung**: Interaktive Charts zur Portfolio-Darstellung
- **Rebalancing**: Empfehlungen zur Portfolio-Anpassung
- **Client-Management**: Verwaltung mehrerer Kunden-Portfolios

## Installation

```bash
npm install
```

## Entwicklung

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Technologie-Stack

- React 18
- TypeScript
- Vite
- Recharts (Visualisierung)
- Lucide React (Icons)
